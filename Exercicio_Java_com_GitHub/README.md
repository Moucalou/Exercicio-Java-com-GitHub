===== GERENCIADOR DE PRODUTOS EM JAVA =====
- Crie um novo repositório no GitHub
- Clone esse repositório em seu computador
- Crie um projeto Java dentro desse repositório e envio o projeto base ao GitHub
- Crie um gerenciador de produtos em Java, que deve conter:
	- Cadastro de produtos
	- Listagem de produtos
	- Exclusão de produtos
	- Alteração de produtos
- A cada etapa da sua codificação, envie seu código atualizado ao GitHub. Ex:
	- Após criar o menu de opções do seu software
	- Após criar listagem de produtos
	- Etc.
- Ao finalizar o projeto, crie um arquivo readme que exemplifica como utilizar seu sistema
- Envie o link ao professor

===== COMO UTILIZAR ====
Com a primeira opção, será possível cadastrar o produto (Somente nome do mesmo)
Com a segunda opção, será possível visualizar os produtos já cadastrados
Com a terceira opção, será possível excluir um dos produtos da lista
Com a quarta opção, será possível alterar/atualizar o produto cadastrado
Com a quinta opção, o programa se encerra
